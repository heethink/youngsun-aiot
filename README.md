# 영선중학교 [데이터로 초록을 구하는 아이(AIoT) 수호대]

부산교육대학교 산학협력단 주관 **디지털새싹** 교육 프로그램의 학생용 온라인 수업 포털 및 교사용 관리 시스템입니다.

---

## 📌 프로그램 개요

- **공식 프로그램명**: 데이터로 초록을 구하는 아이(AIoT) 수호대
- **주관 기관**: 부산교육대학교 산학협력단 (디지털새싹)
- **교육 대상**: 영선중학교 (디지털새싹)
- **수업 일정**: 4차시씩 2회 진행 (총 8차시)
  - **1회차 (2026.11.03 화 / 1~4차시)**:
    - 1차시: 우리 학교 식물의 돌봄 문제 찾기 (사전설문, 관찰·추측 구분, 생성형 AI 탐색)
    - 2차시: 센서로 문제의 원인 분석 (빛·토양 수분 센서 측정, 노이즈 관찰, 메이크코드)
    - 3차시: 데이터로 식물 상태 알림 만들기 (기준값 비교 조건문 코딩, 레인보우 LED 알림)
    - 4차시: AI 식물 의사의 판단 시험하기 (티처블머신 이미지 분류, ifelse-delta AI 모델학습, 센서-AI 교차검증)
    - *활용 도구*: 사전설문(디지털새싹) + 메이크코드 + 티처블머신 + AI 모델학습
  - **2회차 (2026.11.05 목 / 5~8차시)**:
    - 5차시: 스마트팜 키트 조립 및 실습 준비 (IoT 확장보드, 그린하우스 프레임, 센서 조립)
    - 6차시: 내가 설계하는 초록 생명 유지 장치 (토양 수분 기준 물 펌프 자동 급수 및 조명 제어, 식물의사.hex)
    - 7차시: 인공지능과 아이디어 카드로 스마트팜 기능 만들기 (티처블머신 연동 & 아이디어 카드 메이크코드 구현)
    - 8차시: 팀 통합하고 스마트팜 발표하기 (스마트팜 종합 시연 및 발표, 사후설문 및 수료)
    - *활용 도구*: 메이크코드 + 티처블머신 + 사후설문(디지털새싹)

## 🔒 선생님 관리자 페이지 (비밀번호: 2026)

- **비밀번호**: **`2026`**
- **조회 방식**: 학생 개인정보 보호를 위해 **메인 웹사이트에서는 학생 코드가 일체 노출되지 않으며**, 우측 상단 `[선생님 관리자]` 버튼을 눌러 비밀번호 **`2026`**을 입력해야만 학생 관리 포털이 열립니다.
- **학생 관리 탭 주요 기능**:
  - 참여 학생들의 **번호, 이름, 학년(1), 반(3), 6자리 학생코드** 조회 및 복사
  - **11.03 출석**, **11.05 출석**, **사전설문**, **사후설문** 실시간 체크박스
  - 브라우저(`localStorage`) 실시간 자동 저장 (새로고침/재접속 시에도 체크 상태 영구 보존)
  - 실시간 출석 및 설문 완료 현황 통계 집계 카드
  - **엑셀(CSV) 다운로드**: 출석 및 설문 결과를 엑셀 파일로 원클릭 저장

## 🌐 수업 필수 활용 웹 플랫폼 4선

1. **디지털 새싹 공식 포털**: [https://newsac.kosac.re.kr/](https://newsac.kosac.re.kr/)
